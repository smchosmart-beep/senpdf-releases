# 쎈PDF 내려받기

교사를 위한 오프라인 PDF 정리 도구 **쎈PDF**의 설치 파일과 업데이트를 배포하는 곳입니다.

👉 **[최신 버전 받기](https://github.com/smchosmart-beep/senpdf-releases/releases/latest)**

| 파일 | 언제 받나요 |
|---|---|
| `SenPDF-Setup-x.y.z-x64.exe` | 처음 설치하는 PC (전체 설치본, 약 100MB) |
| `SenPDF-x.y.z-small.exe` | 이미 설치된 PC를 직접 업데이트할 때 (약 2~3MB) |
| `senpdf-update.json` | 쎈PDF 자동 업데이트용 정보 파일(받을 필요 없음) |

- 쎈PDF 1.0.0부터는 새 버전이 나오면 프로그램이 자동으로 알려 줍니다. 알림에서 [업데이트]를 누르면 작은 파일만 받아 적용합니다.
- 학교 업무망 등에서 자동 확인이 안 되면 이 페이지에서 `small.exe`를 받아 실행하세요.
- Windows 10 이상 64비트, 사용자 계정 설치(관리자 권한 필요 없음).

## 저작권과 이용약관
© 2026 상명초 김승현, 등촌중 김형훈. All rights reserved.

쎈PDF는 저작권법의 보호를 받는 프로그램입니다. 1.0.3부터 **쎈PDF 이용약관**이 적용됩니다(설치 화면과 프로그램 안 업데이트 창의 [이용약관 보기]에서 볼 수 있습니다).
- 설치 파일은 이 페이지에서만 받아 주세요. 다른 곳(웹하드, 메신저 단체방, 다른 저장소 등)에 다시 올리지 말고, 이 주소를 안내해 주세요.
- 허락 없이 수정·개작하거나, 설치 파일·프로그램 파일을 AI 서비스에 올려 분석하게 하거나 비슷한 프로그램을 만들게 할 수 없습니다.
- 함께 들어 있는 오픈소스 구성 요소(PDF.js, pdf-lib, Electron 등)는 각자의 라이선스를 따릅니다.
