# 쎈PDF 내려받기

교사를 위한 오프라인 PDF 정리 도구 **쎈PDF**의 설치 파일과 업데이트를 배포하는 곳입니다.

👉 **[최신 버전 받기](https://github.com/smchosmart-beep/senpdf-releases/releases/latest)**

| 파일 | 언제 받나요 |
|---|---|
| `SenPDF-Setup-x.y.z-x64.exe` | 처음 설치하는 PC (전체 설치본, 약 100MB) |
| `SenPDF-x.y.z-small.exe` | 이미 설치된 PC를 직접 업데이트할 때 (약 2~3MB) |
| `senpdf-update.json` | 쎈PDF 자동 업데이트용 정보 파일(받을 필요 없음) |

- 쎈PDF 2.5.0부터는 새 버전이 나오면 프로그램이 자동으로 알려 줍니다. 알림에서 [업데이트]를 누르면 작은 파일만 받아 적용합니다.
- 학교 업무망 등에서 자동 확인이 안 되면 이 페이지에서 `small.exe`를 받아 실행하세요.
- Windows 10 이상 64비트, 사용자 계정 설치(관리자 권한 필요 없음).
